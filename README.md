# 电子落款工具 v22.1

本地 PDF 日期落款工具。公开版保留完整源码、Web UI、日期结构识别所需的小型通用模板和测试；删除本地虚拟环境、真实回归 PDF、历史 QA 清单与输出文件。

## 核心边界

自动写入只允许阿拉伯数字；不覆盖原有文字、数字、印章或其他页面内容；定位不确定或存在冲突时交由人工处理；生成后对页面尺寸、旋转、原图像流和允许区域之外的像素变化进行审计。

## 安装与运行

macOS 双击 `启动_macOS.command`，Windows 使用 `启动_Windows.bat`。首次运行会创建本地 `.venv` 并安装 `requirements.txt`。

## 测试

```bash
pip install -r requirements-test.txt
python -m pytest -q
```
